# Условия поставки листового металла

> Вымышленный документ для демонстрации. Поставщик «Альфа-Лист» и все условия придуманы.

Поставщик «Альфа-Лист» поставляет холоднокатаный лист. Отклонение по толщине — не больше 0,08 мм от значения в заказе.

К каждой партии прикладывается паспорт качества. Партию без паспорта склад не принимает и ставит в зону ожидания.

Если партия не соответствует требованиям, отдел закупок отправляет претензию с фото и актом проверки. Поставщик заменяет партию за свой счёт в течение 7 рабочих дней.

На время замены мастер смены может перевести линию на лист из страхового запаса — по согласованию с начальником производства.

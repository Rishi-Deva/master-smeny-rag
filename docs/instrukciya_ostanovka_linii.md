# Инструкция по аварийной остановке линии

> Вымышленный документ для демонстрации.

Аварийная остановка выполняется кнопкой «Стоп» на пульте оператора при угрозе травмы, дыме, искрении, необычном шуме в приводе или утечке масла.

После остановки оператор сообщает мастеру смены и дежурному механику. Запустить линию снова может только дежурный механик после осмотра.

Каждая остановка дольше 20 минут записывается в журнал простоев с причиной и временем. Сводка простоев за сутки уходит начальнику производства каждое утро.

Плановое обслуживание пресса — каждые 400 моточасов. Если срок обслуживания прошёл, механик предупреждает начальника производства до начала смены.

# Регламент действий при обнаружении брака

> Вымышленный документ для демонстрации. Предприятие, названия и цифры придуманы.

При обнаружении брака на линии оператор останавливает подачу заготовок и откладывает подозрительную партию в контейнер с жёлтой маркировкой «На проверку».

Оператор сообщает о браке мастеру смены не позднее чем через 10 минут. Если брак одного вида повторяется три раза за смену, мастер вызывает инженера по качеству и делает запись в журнале несоответствий.

Партия из контейнера «На проверку» не передаётся на склад готовой продукции, пока инженер по качеству не подпишет акт проверки.

Если причина брака — входящий материал, инженер по качеству в течение одного рабочего дня передаёт претензию в отдел закупок (см. условия поставки листа).
